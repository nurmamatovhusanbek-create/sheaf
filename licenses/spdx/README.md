# licenses/spdx

Standard licence texts from the SPDX licence list (https://github.com/spdx/license-list-data, `text/`),
used by `cargo run -p licenses` to build `THIRD_PARTY_LICENSES`. They are the standard wordings: the
copyright lines of each project are in that project (see the upstream URL beside each library in
`licenses/tesseract-bundle.tsv`). `SHA256SUMS` pins the files so a change is a visible diff.
